What I learnt

Binary

Binary is a number system that only uses two digits: 0 and 1. Computers use binary because they work using on and off signals. A 1 can represent on, and a 0 can represent off.

Each binary digit is called a bit. Binary is a base 2 number system, which means it is based on two digits. Computers use binary to store, process, and understand data. For example, 1011 in binary is equal to 11 in decimal.

Decimal

Decimal is the number system that people use every day. It uses the digits 0 to 9 and is used for things like counting, money, measurements, and time.

Decimal is a base 10 number system because it is based on ten digits. It is easier for humans to read and understand compared to binary. This is why we usually use decimal numbers in everyday life.

Hexadecimal

Hexadecimal is a number system that uses 0 to 9 and the letters A to F. The letters A to F represent the numbers 10 to 15. Hexadecimal is a base 16 number system.

Hexadecimal is used in computing because it makes long binary numbers shorter and easier to read. Each hexadecimal digit represents four binary bits. For example, A in hexadecimal is equal to 10 in decimal. Hexadecimal is also used for things like colour codes in graphic design and web development.

What is the Purpose of a Binary Table?

The purpose of a binary table is to help people convert numbers between binary, decimal, and hexadecimal. Computers use 0s and 1s, but humans usually find decimal and hexadecimal easier to read.

Professionals use binary tables to convert numbers more quickly and accurately. This can help when checking network addresses, subnet masks, or colour codes in graphics. The table shows the same value in different number systems and helps reduce mistakes.

Binary Table

A binary table uses place values. In an 8-bit binary number, the place values are 128, 64, 32, 16, 8, 4, 2, and 1 from left to right.

128 64 32 16 8 4 2 1
1 1 0 0 1 1 1 1

Example 1 - Binary to Decimal

The binary number being converted is 1100 1111. A network engineer may need to convert this into decimal when checking IP addresses or subnet masks because computers store values in binary, but humans understand decimal more easily.

Each place value is multiplied by the binary digit. So 1 × 128 = 128, 1 × 64 = 64, 0 × 32 = 0, 0 × 16 = 0, 1 × 8 = 8, 1 × 4 = 4, 1 × 2 = 2, and 1 × 1 = 1.

When the values are added together, the answer is 128 + 64 + 8 + 4 + 2 + 1 = 207. This means 1100 1111 in binary is 207 in decimal.

Example 2 - Decimal to Binary

Decimal to binary conversion is useful because network engineers may need to see which bits are switched on or off. This helps when working with IP addresses, subnetting, and routing.

For example, the decimal number 192 can be converted into binary using the place values 128, 64, 32, 16, 8, 4, 2, and 1. First, 192 - 128 = 64. Then, 64 - 64 = 0.

This means the 128 and 64 columns are switched on, and the rest are switched off. So 192 in decimal is 1100 0000 in binary.

128 64 32 16 8 4 2 1
1 1 0 0 0 0 0 0

Example 3 - Hexadecimal to Binary

The hexadecimal number being converted is 2F. A network engineer might need to convert hexadecimal into binary to understand how the computer processes the value.

Each hexadecimal character represents four binary digits. The hexadecimal value 2 is 0010 in binary. The hexadecimal value F is 1111 in binary.

When they are combined together, 2F in hexadecimal becomes 0010 1111 in binary.
