What I learnt

What is Coding and Programming?

Coding means writing instructions that tell a computer what to do. These instructions are written using a programming language. Coding is used to create things like websites, mobile apps, games, and software.

Programming is the bigger process of planning, writing, testing, and fixing code. It is not just about typing instructions. Programmers need to think about the problem, design the steps, and choose the best way to make the computer complete the task.

An Analogy of Coding

Coding is like baking a cake. The programmer is the baker, and the recipe is the code. The ingredients are the data and parts the program needs to work with. The oven is like the computer because it follows the instructions and turns them into a finished result.

If the recipe is clear and correct, the cake turns out well. In the same way, if the code is written properly, the app, website, or program works correctly. The finished cake is like the final program that the user can enjoy.

How Does Coding Work?

Coding works by giving a computer clear instructions to follow. A coder writes these instructions using a language such as Python, JavaScript, C++, Java, or C#. These languages are easier for humans to read, but computers do not understand them directly.

The code must be translated into machine code, which is made from 0s and 1s. Tools like compilers and interpreters help turn the code into instructions the computer can understand. The computer then follows the instructions step by step.

Coding also involves algorithms, which are step-by-step methods for solving problems. Coders test and debug their code to find mistakes and fix them. This helps make sure the program works properly and does what it is meant to do.

An Analogy of Programming

Programming is like giving instructions to a robot to build a LEGO set. The robot is the computer, the instructions are the code, and each LEGO piece is a piece of data. The robot cannot guess what to do, so the instructions must be clear.

If the instructions are wrong, the robot may build something strange or stop working. This is similar to a program crashing when there is a bug. That is why programmers need to write clear instructions and check their work carefully.

How Does Programming Work?

Programming starts with a problem that needs to be solved. This could be making a character move in a game, sending a message, storing information, or showing something on a website. The programmer breaks the problem into smaller steps so the computer can follow them.

After planning the steps, the programmer writes the code using a programming language. The computer is very strict, so even a small mistake can stop the program from working. The code is then translated using a compiler or interpreter so the computer can run it.

When the program runs, the computer follows each instruction in order. It can store data, make decisions, check conditions, and show results. If something goes wrong, the programmer tests the program and fixes the errors. This process is called debugging.

The Programming Process

Programming usually follows a simple process. First, you plan the design and decide what the program should do. Next, you write the instructions using code. Then, you let the computer run the program and check if it works correctly.

If errors happen, you fix them and test the program again. This cycle repeats until the program works properly. Programming is not only about writing code, it is also about problem solving, planning, testing, and improving the final result.

Banking Application in Python

Building the User Interface and Menus

In my banking app, I used the print() function to show the main menu, account details, and messages for the user. This helped the user understand what was happening in the program, such as whether a withdrawal was successful or what options they could choose.

I used the input() function so the user could interact with the app by typing their choices and details. I also used .lower() on some inputs so the program could understand answers like “YES”, “Yes”, or “yes” in the same way. This made the app easier to use and helped prevent simple input errors.

Handling Money and Transactions

The input() function reads everything as text, so I used float() to turn money amounts into decimal numbers. This allowed the program to correctly add deposits and subtract withdrawals from the user’s balance.

I used .append() to add a new message to the user’s transaction history whenever they deposited or withdrew money. I also used .get() to safely check if an account was banned. This is useful because if the banned value is missing, the program can still continue without crashing.

Making the Bank Feel More Realistic

To make the banking app feel more realistic, I used random.randint() to create an 8-digit account number and a 4-digit PIN for new users. I also used time.sleep() to add a short pause when creating an account, making it feel like the app was loading.

For the savings account, I used threading.Thread() and .start() to run an interest loop in the background. This meant the app could add interest to savings without freezing the main menu. Finally, I used exit() to close the app when the user chose to log out.
