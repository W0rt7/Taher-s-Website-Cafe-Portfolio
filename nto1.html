What I learnt

The DIKW

DIKW stands for Data, Information, Knowledge and Wisdom. It shows how random numbers and unprocessed information can become useful. Data is mainly just raw facts without meaning and context. When we organise data and understand what it means, it then becomes information. When we learn, understand information and know how to use it, that will become knowledge. Wisdom is when we use what we know to make the best choices. This model can help us explain how we can use starting from raw data turning them into smart decisions

The 4Vs

The 4Vs are a way to understand what makes big data different from regular data. They focus on how much data there is (Volume), how fast its created (Velocity), the different types of data (Variety) and how accurate or reliable it is (Veracity). Looking at data using the 4Vs helps businesses and analysts' handle large datasets more efficiently.

Cleansing Data

How I Cleaned the Data

I cleaned the data using Excel by first looking through the survey responses to find any errors. I corrected spelling mistakes such as the shop names for example correcting “Tescoo” to “Tesco” and fixing missing letters in “Gregs” to “Greggs”. This made sure all responses could be counted correctly.

I also checked that the Yes and No responses didn't have any spelling mistakes and easy to read. I used conditional formatting to apply colour so that any cell which is “Yes” are green and any cell which is red appear red. This doesn't change the data itself but makes the responses easier and clear to read. This helped me quickly analyse how many people answered Yes or No and reduced the chances of misinterpreting the data.

To calculate the totals, I used the function =COUNTIF on the response columns. This allowed me to count how many “Yes” or “No” appeared in each column. Using the formulas increased accuracy and if any of the data changed the results would update automatically.

Finally, I reviewed the dataset to make sure that they were all correctly formatted, confirming the data was clean and ready for analysis and visualisation.
