Unit 4 - Networking

What I learnt

Local Area Network

A Local Area Network, also known as LAN, is a network that connects devices in a small area. This could be inside a home, school, office, or one building. Devices such as computers, laptops, phones, and printers can connect to the same network. In most homes, the devices connect through one router, but in larger buildings there may be more than one router to support more users.

One advantage of LAN is that it is usually cheap and easy to set up. It can also transfer data quickly between devices, which helps when sharing large files or backing up data. Software and resources can also be shared across the local network. However, LAN has a limited range and is mainly useful in one building. It can also slow down if too many devices are connected, and it is not designed for sending data over long distances.

Wireless Local Area Network

A Wireless Local Area Network, also known as WLAN, is similar to a LAN but it connects devices wirelessly. It uses radio waves instead of lots of cables. WLAN is commonly used in homes, schools, cafes, and offices because people can connect laptops, phones, and tablets without needing a wired connection. Devices only need to be within the wireless range to connect.

One advantage of WLAN is that it is simple to set up and gives users more freedom to move around. It can also be cheaper because fewer cables are needed. WLAN can support many devices and makes it easier for people to access the internet. However, because it is wireless, it can be more vulnerable to hacking if it is not secured properly. It can also be affected by interference, weak signals, and too many devices using the network at the same time.

Personal Area Network

A Personal Area Network, also known as PAN, is a small network used around one person. It usually has a short range, often around ten metres. A common example is Bluetooth, such as connecting wireless earphones to a phone, a phone to a speaker, or a computer to a printer. PAN is useful for connecting personal devices quickly.

One advantage of PAN is that it is flexible and easy to use. Many devices can connect automatically without much setup, especially with Bluetooth. It can also be fairly secure when encryption is used. However, PAN has a short range and can be unreliable if the connection is weak. It also depends on the devices being close together and does not work well for sharing data across large areas or to many devices at once.

OSI Model 7 Layer Model

Layer 1: Physical Layer

The Physical Layer is about the hardware and how data physically moves. It sends raw bits, which are 1s and 0s, through cables, fibre optics, or Wi-Fi signals. It is basically the electrical or wireless signal that carries data from one device to another.

Layer 2: Data Link Layer

The Data Link Layer takes the bits and puts them into small packages called frames. It also checks for errors so data can travel correctly between two directly connected devices. It is like putting a letter into the correct envelope with the correct address.

Layer 3: Network Layer

The Network Layer decides the path data should take to reach the correct location. It uses addresses like IP addresses to find the best route across different networks.

Layer 4: Transport Layer

The Transport Layer makes sure data gets to the correct place. It splits large messages into smaller parts and puts them back together at the end. If some parts are missing or arrive in the wrong order, it helps fix the problem.

Layer 5: Session Layer

The Session Layer manages communication between applications. It starts, controls, and ends connections so apps can talk to each other properly without confusion.

Layer 6: Presentation Layer

The Presentation Layer changes data into a format the receiving application can understand. It can also handle encryption and conversion so data is readable and secure.

Layer 7: Application Layer

The Application Layer is the layer users see and use. It includes things like web browsers, games, and apps that send or receive data over a network. It lets users access network services without needing to understand all the layers below.

Transmission Control Protocol

Transmission Control Protocol, also known as TCP, is a communication standard used to send data across a network. TCP breaks data into smaller packets and sends them to the correct location. It makes sure the packets arrive successfully and in the correct order.

If any packets are missing, TCP automatically sends them again. TCP also uses a process called a three-way handshake, which creates a reliable connection between two devices before data is sent. This makes TCP very reliable, but it can be slower than other protocols. It is often used for web browsing, file transfers, and emails.

Internet Control Message Protocol

Internet Control Message Protocol, also known as ICMP, is a network layer protocol found in Layer 3 of the OSI Model. It works with IP and is used by network devices such as routers and hosts to send control messages, error messages, and status information about the network.

ICMP helps identify network problems such as routing issues, timeouts, or devices that cannot be reached. If a message cannot be delivered, ICMP can send an error message back to explain what went wrong. Tools like ping and traceroute use ICMP to test connections and track the path data takes. This makes ICMP important for troubleshooting network faults.

Cisco Packet Tracer

What Went Well

The planning, design and building of the network on Cisco Packet Tracer for Horizon Technical College went well overall. I successfully met all the requirements given by the client. In the planning stage, I used Visio to create the diagram of the network, showing the 5 PCs and 1 printer in each office connected to a switch, and all three switches connected to a central router. This helped me plan how everything would be connected before building it.

In the design stage, I assigned IP addresses to all PCs and printers in each room. I made sure each office had its own subnet, such as 192.168.1.0, 192.168.2.0 and 192.168.3.0. I also set a default gateway for each room so the devices could communicate through the router. This allowed me to successfully ping the devices and keep the network organised.

During the building and testing stage, I connected all the devices in each room to their switches and then connected the switches to the router. I tested the network using ping commands and confirmed that all PCs and printers could communicate with each other successfully.

Overall, the network is suitable for Horizon Technical College because it is reliable and meets all the client requirements. It can also be expanded in the future by adding more devices without needing to redesign the whole system.
